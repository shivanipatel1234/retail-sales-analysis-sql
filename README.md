Retail Sales Analysis Using SQL
Project Overview
This project analyses retail sales data using SQL and SQLite to understand revenue, customer spending, product performance, and order status.

Database Tables
Customers: Customer details and cities
Products: Product names, categories, and prices
Orders: Order dates and order statuses
Order_Items: Products, quantities, and item prices for each order

Key Analysis
Calculated total and delivered revenue
Analysed revenue by customer and product
Compared category-wise sales
Examined monthly delivered revenue
Counted orders by status
Identified top customers by delivered revenue

Tools Used
SQL
SQLite
